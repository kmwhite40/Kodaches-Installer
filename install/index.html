Install Kodaches

One zip installs the whole Kodaches build: the add-on, its skin and home screen, streaming settings, the TV guide and the free apps. Everything comes from the Kodaches repository and the official Kodi and SlyGuy repositories, so Kodi keeps it up to date. The steps are the same on every device; only installing Kodi itself differs.

First install Kodi 20 or newer: Android TV · Fire TV · Windows, Linux, macOS. Then, in Kodi:

  1. Allow add-ons from outside the official repository. Settings (gear) → System → Add-ons → turn on Unknown sources → Yes.
  2. Add the Kodaches source. Settings → File manager → Add source → <None> → type
    https://kmwhite40.github.io/Kodaches-Installer/kodi/
    → OK. Name it kodaches → OK.
  3. Install the build. Settings → Add-ons → Install from zip file → kodaches → plugin.program.kodaches.build-1.0.0.zip.
  4. Say Yes. Kodaches asks "Install the Kodaches build?" → Yes. Kodi then asks before each download ("Add-on required … download?", with No selected: move to Yes) and whether to keep the new skin (Yes). That is all: the home screen switches to Kodaches when it is done.
Repository only: to install just the Kodaches add-on without the build, use repository.kodaches-1.1.0.zip in step 3 instead, then Add-ons → Install from repository → Kodaches Repository → Video add-ons → Kodaches. The build can be added later from Kodaches → Settings & looks → Set up the Kodaches build.

Updates

Kodi checks the Kodaches repository by itself (about once a day) and installs updates. To check now: Kodaches → Settings & looks → Check for updates.
