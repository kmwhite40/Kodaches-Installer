Install Kodaches

Kodaches installs from its own Kodi repository, so Kodi keeps it up to date. The steps are the same on every device; only installing Kodi itself differs.

First install Kodi 20 or newer: Android TV · Fire TV · Windows, Linux, macOS. Then, in Kodi:

  1. Allow add-ons from outside the official repository. Settings (gear) → System → Add-ons → turn on Unknown sources → Yes.
  2. Add the Kodaches source. Settings → File manager → Add source → <None> → type
    https://kmwhite40.github.io/Kodaches-Installer/kodi/
    → OK. Name it kodaches → OK.
  3. Install the repository. Settings → Add-ons → Install from zip file → kodaches → repository.kodaches-1.1.0.zip. Wait for "Kodaches Repository installed".
  4. Install Kodaches. Add-ons → Install from repository → Kodaches Repository → Video add-ons → Kodaches → Install.
  5. Open it. Add-ons → Video add-ons → Kodaches. The first time, it loads the channel lists (a few seconds).
Make it the full Kodaches build: Kodaches → Settings & looks → Set up the Kodaches build. It installs the Kodaches skin and home screen, applies streaming settings, and offers the streaming apps. Kodi asks you to confirm each install and to keep the new skin.

Updates

Kodi checks the Kodaches repository by itself (about once a day) and installs updates. To check now: Kodaches → Settings & looks → Check for updates.
