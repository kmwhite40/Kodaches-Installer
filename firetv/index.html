Fire TV

Fire TV Stick (2nd gen and newer), Fire TV Stick 4K / 4K Max, Fire TV Cube, and Fire TV Edition televisions.

Kodi is not in Amazon's Appstore, so Fire TV needs one setting changed to install it. Fire TV models that run Amazon's newer Vega OS (for example the Fire TV Stick 4K Select) do not run Android apps at all, so Kodi cannot be installed on them.
  1. On the Fire TV home screen, search for Downloader (by AFTVnews) and install it.
  2. Settings → My Fire TV → Developer options → Install unknown apps → turn Downloader on. (No Developer options? Settings → My Fire TV → About → press Select on your device name 7 times.)
  3. Open Downloader, select the address box and type kodi.tv/download/android → Go. Choose ARMV7A (32BIT); it is the build that runs on every Fire TV. Install it when asked.
  4. Open Kodi from Your Apps & Channels (hold Home → Apps to find it).
  5. Follow the five install steps. In step 2, the source address is:
    https://kmwhite40.github.io/Kodaches-Installer/kodi/

To come back to this page from Downloader, type https://kmwhite40.github.io/Kodaches-Installer/firetv/.

Good to know

  • Pick the Smart TV or Performance look: both use a small video cache suited to the Fire TV Stick's memory.
  • Delete the Kodi installer file Downloader offers to remove after installing; it frees space.
