Windows, Linux and macOS

  1. Install Kodi from kodi.tv/download:
    • Windows: the 64-bit installer, or Kodi from the Microsoft Store.
    • Linux: your distribution's kodi package, Flatpak (tv.kodi.Kodi on Flathub), or LibreELEC for a dedicated TV box.
    • macOS: the official .dmg (Apple silicon or Intel).
  2. Follow the five install steps. On a computer you can also download the repository zip from Downloads and choose it in "Install from zip file".
